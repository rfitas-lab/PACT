# Data and third-party material notice

This repository is the paper-free public reproduction repository for the PACT transfer benchmark.

The MIT-style project code and benchmark outputs created for this work can be reproduced from the declared protocol and scripts in `benchmark/`. The repository intentionally does **not** contain the manuscript, manuscript PDF, LaTeX submission package, or publisher-formatted copies of the paper.

Some earlier application studies referenced by the manuscript used experimental probe archives, synchronized images, derived photograph panels, and/or publisher assets whose redistribution permissions are not established by the project software license. Those third-party or permission-sensitive files are therefore not copied into this repository. Their omission does not affect reproduction of the new matched-information PACT benchmark, whose complete numerical inputs are declared in `benchmark/protocol.json`.

Earlier application calculations and their original attribution remain associated with their source project archive. This repository does not relicense those external data or media.
